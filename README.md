Aplicación móvil de organización integral y gestión diaria enfocada en el equilibrio personal. Está diseñada especialmente para ayudar a **personas con TDAH** (Trastorno por Déficit de Atención e Hiperactividad) y a cualquier persona que busque estructurar su día a día de forma consistente en un solo lugar.

---

## Sobre el proyecto

Este proyecto nació como un proceso de aprendizaje autodidacta. 
* **Primera versión:** Desarrollada de forma nativa en **Android (Java)** utilizando arquitectura MVVM, Room y RxJava.
* **Versión actual:** Una reescritura completa desde cero utilizando **Flutter** y **Dart**, con el objetivo de ofrecer una experiencia multiplataforma (**Android e iOS**) fluida, moderna y con una interfaz accesible y adaptada al enfoque constante.

## Tecnologías utilizadas

* **Lenguaje:** Dart
* **Framework:** Flutter
* **Gestión de estado:** [Ej: Riverpod / BLoC / Provider]
* **Base de datos local:** [Ej: Isar / Hive / Sqflite]
* **Autenticación y Backend:** Firebase Authentication

## Características principales (En desarrollo)
* Interfaz minimalista y libre de distracciones.
* Herramientas de organización adaptadas para el manejo del tiempo y la atención.
* Almacenamiento local rápido y seguro.
* Sincronización y autenticación de usuarios.
